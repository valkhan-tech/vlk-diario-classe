Instalação e uso

Resumo do guia de configuração (README) e da rotina diária. Faz-se uma única vez; depois o app é só abrir no tablet.

Atenção: por causa do item P01, hoje o app não lembra a conta/arquivo entre aberturas — será necessário entrar e escolher o arquivo de novo até ser corrigido.

1. Publicar no GitHub Pages

  1. Criar conta no GitHub e um repositório público (ex.: diario-musical).
  2. Enviar os arquivos do projeto (index.html, pastas css/ e js/). O README antigo cita só index.html, mas hoje o app precisa das três partes.
  3. Em Settings → Pages: Deploy from a branch → main → / (root).
  4. O endereço será https://SEU-USUARIO.github.io/diario-musical/.
  5. No Chrome do tablet: menu ⋮ → Adicionar à tela inicial.

2. Colocar o Excel no OneDrive

Enviar a planilha para o OneDrive pessoal. O arquivo em uso hoje é Diario_Pedagogico_Musical_demo.xlsx; o campo do app vem preenchido com /Documentos/Diario_Pedagogico_Musical.xlsx, então é preciso digitar o caminho/nome real (ou usar Navegar no OneDrive). O arquivo não deve ficar no GitHub.

3. Registrar o app no Azure (uma vez)

CampoValor
NomeDiário Pedagógico Musical
Tipos de contaSomente contas pessoais Microsoft
PlataformaSingle-page application (SPA) com o URI do GitHub Pages (usar “Web” causa o erro AADSTS70002, tratado no log do app)
Permissões (Graph, delegadas)Files.ReadWrite e User.Read

O Client ID padrão já está no código (DEFAULT_CLIENT_ID em config.js); o campo para trocá-lo existe no HTML mas está oculto.

4. Primeira conexão

  1. Aba Config → Entrar com Microsoft (aviso “app não verificado” → Informações avançadas → continuar).
  2. Informar o caminho do arquivo e tocar em Buscar (ou Navegar no OneDrive, que lista os .xlsx da raiz).
  3. O app lê a planilha automaticamente. Depois, Atualizar tudo reenvia pendências e recarrega os dados.

SintomaCausa provável / ação

“Arquivo não encontrado”Caminho diferencia maiúsculas/minúsculas e deve começar com /.
Dados não aparecem após reabrirEsperado hoje (P01/P08): conectar e usar Atualizar tudo.
