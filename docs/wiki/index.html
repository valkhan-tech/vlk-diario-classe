🎹 Diário Pedagógico Musical

Aplicativo web para professores de música registrarem aulas, acompanharem o progresso e controlarem a parte financeira dos alunos, usando uma planilha Excel no OneDrive como banco de dados.

Atenção: esta Wiki foi escrita a partir do código atual (commit 813326d). A página Pendências e lacunas lista 22 pontos encontrados — três deles são críticos (P01, P02 e P09). Veja também as Regras de negócio e o Roadmap proposto.
Código movido: o app descrito nesta Wiki foi movido para a pasta legacy/ do repositório. Os caminhos citados (por exemplo js/app.js) passam a ser legacy/js/app.js. A nova arquitetura está em docs/stack-proposta.md.
Levantamento finalizado em 17/11/2026. Todas as perguntas de negócio foram respondidas e estão registradas em Regras de negócio; as suposições que tomei estão em Pendências para correção. Nenhum código do app e nenhum arquivo real foi alterado.

O que é

Um app web estático (HTML + CSS + JavaScript puro, sem framework e sem servidor próprio) pensado para o navegador de um tablet. Ele conversa direto com o Microsoft Graph para ler e escrever no arquivo Diario_Pedagogico_Musical.xlsx guardado no OneDrive pessoal da professora. É hospedado no GitHub Pages.

Público: professora(es) de Piano, Órgão e Flauta (contexto de ensino musical ligado à igreja: hinos, “prontidão para culto”, oficialização).
