Proposta de layout da planilha

Alterações necessárias no Diario_Pedagogico_Musical_demo.xlsx para cumprir as decisões tomadas. É uma proposta para aprovação: o arquivo real não foi alterado. A professora continuará podendo editar tudo à mão no Excel.

Princípios: (1) não quebrar o que ela já usa — colunas existentes mantêm posição e significado; (2) só acrescentar colunas e abas; (3) fórmulas e validações existentes ficam; (4) o app nunca grava em colunas com fórmula; (5) toda linha que o app grava tem um identificador estável.

Abas novas

AbaColunas
MétodosA ID · B Nome · C Tipo (lista TIPO MÉTODO) · D Nível (lista NÍVEL MÉTODO) · E Instrumento (opcional) · F Total de Lições (fórmula =CONT.SE(Lições[ID Método];A2)) · G Ativo (Sim/Não) · H Observações
LiçõesA ID · B ID Método · C Ordem (número) · D Título/Descrição · E Observações
Aluno × MétodoA ID · B ID Aluno · C ID Método · D Data Início · E Situação (lista SITUAÇÃO MÉTODO) · F Data da Situação · G Observação
Avaliações de liçãoA ID · B ID Aluno · C ID Lição · D Status (lista STATUS LIÇÃO) · E Data da Tentativa · F ID Aula (opcional) · G Observação
  • Avaliações de lição é um registro só de acréscimo: cada tentativa fica com sua data real. A data do status exibida é a do primeiro registro da sequência atual de mesmo status (regra da professora); o tempo na lição vem dessas datas.
  • Lição sem nenhum registro conta como Pendente para os métodos que o aluno tem Iniciados.
  • Hinário = método do tipo Hinário (50 lições de jovens, 430 do culto oficial). Para cadastrar em lote, o app aceita uma lista colada.

Nota: as fórmulas acima estão com os nomes de função do Excel em português (SE, E, HOJE, CONT.SE) e separador “;”; o arquivo guarda internamente os nomes em inglês (IF, AND, TODAY, COUNTIF).

Tabelas do Excel

Recomendo converter cada aba de dados em uma Tabela do Excel (Inserir → Tabela): o filtro e a ordenação continuam como hoje, as validações e fórmulas são herdadas por linhas novas, e o Microsoft Graph consegue acrescentar linhas na tabela com as colunas calculadas preenchidas. Os intervalos fixos do Dashboard (C3:C57) deixam de ser problema. Pendência de verificação: testar a convivência com os dois cabeçalhos (título + cabeçalho) que as abas têm hoje; pode ser necessário mover o título para fora da tabela.

Compatibilidade e riscos

  • Nenhuma coluna existente muda de posição; o Excel continua utilizável sem o app.
  • O Dashboard precisa de ajuste de fórmulas (Financeiro) — fórmulas novas estão descritas acima.
  • Se a professora inserir linhas ou ordenar à mão, o app localiza por ID e continua correto (P22).
  • As colunas novas ficam à direita; quem abrir o arquivo antigo no app antigo não é afetado, mas o app atual (com os defeitos P02/P06/P07) não deve ser usado contra o arquivo alterado.
